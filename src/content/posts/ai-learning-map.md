## 第一篇：AI学习总路线——从零到一的知识地图

人工智能学习不是一条单线课程，而是一张由数学、编程、算法、工程和领域知识交织而成的网络。很多人失败，不是因为不够聪明，而是因为路线混乱：今天学 Python，明天看 Transformer，后天又去调参，最后什么都没留下。一个可行的 AI 学习路线，应当遵循“基础 → 核心 → 应用 → 工程 → 专项”的顺序，同时坚持项目驱动。

### 一、AI 知识地图的五个层次

第一层是**数学与编程基础**。数学包括线性代数、概率统计、微积分和优化；编程以 Python 为核心，辅以 NumPy、Pandas、Matplotlib、Git、Linux 和 SQL。

第二层是**机器学习**。理解监督学习、无监督学习、强化学习的基本范式，掌握线性回归、逻辑回归、决策树、随机森林、SVM、聚类、降维和集成学习。

第三层是**深度学习**。从 MLP 到 CNN、RNN、LSTM，再到 Attention 和 Transformer。需要理解反向传播、损失函数、优化器、正则化和训练技巧。

第四层是**大模型与 AI 工程**。包括预训练、微调、提示工程、RAG、Agent、向量数据库、推理优化和部署。

第五层是**领域与伦理**。AI 最终要落到医疗、金融、教育、制造、内容等场景中，同时必须考虑隐私、偏见、安全、版权和 alignment。

### 二、推荐学习阶段

**阶段 0：启蒙（1—2 周）**  
了解 AI、机器学习、深度学习、大模型的基本概念，跑通第一个 Python 程序，安装 Jupyter Notebook。目标不是精通，而是建立地图感。

**阶段 1：基础（1—2 个月）**  
学习 Python 语法、NumPy、Pandas、Matplotlib，同时补线性代数和概率统计。能做数据清洗、可视化和简单统计分析。

**阶段 2：机器学习（2—3 个月）**  
系统学习 scikit-learn，完成泰坦尼克、房价预测、鸢尾花分类等项目。理解训练集、验证集、测试集、交叉验证、过拟合和评估指标。

**阶段 3：深度学习（3—4 个月）**  
学习 PyTorch，完成 MNIST、CIFAR-10、文本分类、情感分析。理解 CNN、RNN、Transformer 的基本结构。

**阶段 4：大模型与工程（3—6 个月）**  
从调用 API 开始，逐步做 RAG 知识库、Agent 工具调用、LoRA 微调、模型部署。学习 LangChain、LlamaIndex、Hugging Face、vLLM、Docker。

**阶段 5：专项与持续学习**  
选择方向：CV、NLP、多模态、强化学习、推荐系统、AI Infra、AI 安全。读论文、复现项目、参加 Kaggle 或开源。

### 三、学习原则

1. **项目驱动**：每学一个概念，就写一个最小可运行项目。
2. **费曼技巧**：能用大白话讲清楚，才算真正理解。
3. **复现优先**：经典论文和经典项目至少完整复现一次。
4. **读源码**：从 scikit-learn、PyTorch、Hugging Face 的示例入手。
5. **持续输出**：写博客、做笔记、发 GitHub，形成反馈循环。

### 四、常见误区

- 只收藏课程，不动手写代码。
- 追求“最新”，忽视数学和经典算法。
- 只调包，不理解原理。
- 没有评估意识，模型上线后才发现问题。
- 忽视工程能力：Git、Linux、SQL、Docker、API 部署。

### 五、总结

AI 学习路线的核心不是“学完”，而是“构建能力栈”。数学让你理解原理，编程让你实现想法，机器学习给你方法论，深度学习给你表示能力，大模型和工程让你把能力产品化。最有效的路线是：**基础打牢、项目贯穿、由简入繁、持续迭代**。

## 扩展学习笔记

### 这一篇要解决的问题

- 搞清楚学习对象是什么，避免一上来就陷入工具和教程碎片。
- 建立最小可执行路线，把知识点变成可以完成的小项目。
- 用复盘检查自己是否真正理解，而不是只完成了观看和收藏。

### 推荐实践方法

1. **先跑通一个最小案例**：不追求完美，先让代码、数据、结果完整闭环。
2. **再拆解关键概念**：把每个概念写成“是什么、为什么、怎么用、常见错误”。
3. **最后做一次迁移**：换一个数据集、场景或任务，验证自己是否能独立复现。

### 学习检查清单

- 我能不能用自己的话解释这个主题的核心概念？
- 我能不能指出它适合解决什么问题、不适合解决什么问题？
- 我有没有留下代码、笔记、图示或项目结果？
- 我能不能把它接到下一个阶段继续学习？

### 常见扩展方向

- **项目化**：把知识点做成小作品，比如预测、分类、问答、检索、自动化脚本。
- **工程化**：考虑数据质量、版本管理、部署方式和可维护性。
- **表达化**：把学习过程写成文章，训练自己讲清楚复杂问题的能力。

### 小结

AI 学习总路线 不适合只靠“看懂”完成。真正有效的学习，是每一阶段都留下可运行、可解释、可复盘的成果。
