## 第二篇：数学与编程——AI 学习的底层能力

很多人问：学 AI 要不要数学？答案是：要，但不是先学完数学再学 AI，而是“边用边学”。数学是理解模型的语言，编程是实现模型的工具。没有这两者，AI 学习会停留在调包和背概念。

### 一、AI 需要的数学知识

**线性代数**是深度学习的骨架。向量、矩阵、张量、矩阵乘法、转置、逆、特征值、特征向量、SVD、范数，这些概念贯穿神经网络、嵌入、注意力机制和降维。

**概率统计**是机器学习的灵魂。随机变量、概率分布、条件概率、贝叶斯定理、期望、方差、协方差、最大似然估计、假设检验、置信区间。分类问题、生成模型、评估指标都离不开概率。

**微积分与优化**是训练模型的基础。导数、偏导数、梯度、链式法则、雅可比矩阵、海森矩阵、凸优化、梯度下降、随机梯度下降、动量、Adam。反向传播本质就是链式法则的高效实现。

**信息论**帮助理解损失函数。熵、交叉熵、KL 散度、互信息。交叉熵损失、对比学习、知识蒸馏都与此相关。

### 二、AI 需要的编程能力

**Python**是 AI 第一语言。掌握语法、函数、类、异常、文件操作、虚拟环境、包管理。

**NumPy**是数值计算核心。数组、广播、索引、切片、矩阵运算、随机数。能用手写线性回归和 K-means。

**Pandas**是数据处理核心。DataFrame、Series、缺失值、分组、合并、透视表、时间序列。

**Matplotlib / Seaborn**用于可视化。数据分布、相关性、训练曲线、混淆矩阵。

**Git / Linux / SQL**是工程基础。不会 Git 无法协作，不会 Linux 难以部署，不会 SQL 难以取数。

**PyTorch**是深度学习首选框架。张量、自动求导、nn.Module、DataLoader、优化器、GPU 训练。

### 三、学习路线

**第 1—2 周：Python 基础**  
变量、循环、函数、列表、字典、类、文件读写。每天写 10—20 行代码。

**第 3—4 周：NumPy + Pandas**  
用 NumPy 实现矩阵乘法、梯度下降；用 Pandas 清洗一份真实数据集。

**第 5—6 周：数学补强**  
看 3Blue1Brown 的线性代数、微积分系列；用 Python 验证矩阵运算和梯度。

**第 7—8 周：从零实现算法**  
手写线性回归、逻辑回归、KNN、K-means、简单神经网络。不要调库，先用 NumPy。

### 四、实践项目

1. **线性回归从零实现**：生成数据，定义损失，手动求梯度，更新权重。
2. **逻辑回归分类**：用 NumPy 实现 sigmoid、交叉熵、梯度下降。
3. **K-means 聚类**：在二维数据上实现聚类并可视化。
4. **手写数字分类**：用 PyTorch 训练 MLP，理解 Dataset、DataLoader、训练循环。
5. **数据清洗项目**：用 Pandas 处理缺失值、异常值、类别编码。

### 五、常见误区

- **数学恐惧症**：不必先学完数学分析再学 AI，够用即可，遇到再补。
- **只看视频不写代码**：编程是肌肉记忆，必须动手。
- **追求高级框架**：基础不牢，PyTorch 也只能复制粘贴。
- **忽视调试能力**：打印形状、检查数据类型、可视化中间结果，是 AI 工程师的日常。
- **不做版本管理**：Git 是基本素养。

### 六、总结

数学和编程是 AI 的“双底座”。数学让你知道为什么，编程让你知道怎么做。最有效的学习方式是：**用项目驱动数学，用数学反哺项目**。当你能用 NumPy 手写一个简单的神经网络，并解释每一步的数学含义时，你就真正跨过了 AI 的第一道门槛。

## 扩展学习笔记

### 这一篇要解决的问题

- 搞清楚学习对象是什么，避免一上来就陷入工具和教程碎片。
- 建立最小可执行路线，把知识点变成可以完成的小项目。
- 用复盘检查自己是否真正理解，而不是只完成了观看和收藏。

### 推荐实践方法

1. **先跑通一个最小案例**：不追求完美，先让代码、数据、结果完整闭环。
2. **再拆解关键概念**：把每个概念写成“是什么、为什么、怎么用、常见错误”。
3. **最后做一次迁移**：换一个数据集、场景或任务，验证自己是否能独立复现。

### 学习检查清单

- 我能不能用自己的话解释这个主题的核心概念？
- 我能不能指出它适合解决什么问题、不适合解决什么问题？
- 我有没有留下代码、笔记、图示或项目结果？
- 我能不能把它接到下一个阶段继续学习？

### 常见扩展方向

- **项目化**：把知识点做成小作品，比如预测、分类、问答、检索、自动化脚本。
- **工程化**：考虑数据质量、版本管理、部署方式和可维护性。
- **表达化**：把学习过程写成文章，训练自己讲清楚复杂问题的能力。

### 小结

数学与编程基础 不适合只靠“看懂”完成。真正有效的学习，是每一阶段都留下可运行、可解释、可复盘的成果。
