## 2025.02 至 2025.10：组织、开发与竞赛并进

- 当选校团委科创赛事服务部部长，参与赛事宣传、报名组织、流程协调和团队协作。
- 系统学习 Java 与 Python，完成图书管理、数据可视化、后端接口等阶段性练习。
- 团队推进“鲁遇”文旅系统，覆盖 Vue、Spring Boot、MySQL、微信小程序、支付与部署运维。
- 独立推进社区瑜伽馆/管理类系统练习，补足权限、数据、消息队列、安全合规和部署流程。
- 通过程序设计大赛、蓝桥杯等竞赛训练算法、工程实现和限时问题拆解能力。

这一阶段的关键词是“成型”：开始把学习变成项目，把项目变成可展示的能力证据。
