数坞基于 HarmonyOS 与 Spring Cloud 微服务架构，搭建从传感器采集、边缘计算到云端分析的完整链路。系统面向高温、粉尘等负碳建材生产环境，支持设备检测、维保决策与生产数据看板。

## 关键实现

- 定制生产环境下的视觉检测流程，目标准确率 96% 以上。
- 支持 Modbus、OPC UA、MQTT 等工业协议，可接入 20 余种产线设备。
- 使用 TDengine 存储时序数据，结合流式计算完成实时异常检测与预警。
- 展示产线 OEE、能耗和碳排放等关键指标。
